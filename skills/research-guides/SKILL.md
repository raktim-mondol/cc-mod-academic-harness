# Academic Harness guides

Each file under `references/` is one area of guidance. Read only the file for the area you are working in.

| File | Read when |
|---|---|
| `references/writing-quality.md` | editing a finished draft that reads machine-generated |
| `references/paper-lifecycle.md` | outside an ah.yaml project: idea evaluation, drafting, pre-submission review |
| `references/reproducible-analysis.md` | running or rerunning an analysis that will be reported |
| `references/provenance-audit.md` | tracing where a number, figure or claim came from |
| `references/deep-research.md` | a survey-grade, multi-source investigation |
| `references/specialists.md` | delegating review, research or design work to a specialist agent |
| `references/literature-and-the-web.md` | finding papers, databases, journals, or web sources |
| `references/reading-papers.md` | reading, downloading or converting papers; clinical evidence; data and journal policy; paper integrity |
| `references/reference-library.md` | managing a project's reference library and BibTeX |
| `references/systematic-reviews.md` | protocols, screening, extraction, PRISMA |
| `references/meta-analysis.md` | pooling effect sizes |
| `references/grade-certainty.md` | rating certainty of evidence |
| `references/reporting-checklists.md` | CONSORT, PRISMA, STROBE and similar checklists |
| `references/deep-review.md` | a multi-pass engine review of a manuscript |
| `references/study-planning.md` | designing a study, power, sampling, pre-registration |
| `references/study-conduct-and-grants.md` | ethics applications, data management, grant writing |
| `references/hypothesis-tournaments.md` | ranked, multi-round hypothesis generation |
| `references/identity-and-audits.md` | ORCID, funders, authorship and local audits |
| `references/references-and-citation.md` | formatting, resolving and checking citations |
| `references/submission.md` | cover letters, rebuttals, response to reviewers, submission packages |
| `references/figures.md` | making or checking figures and diagrams |
| `references/databases-and-toolkits.md` | domain databases and science toolkits |
| `references/discovery-and-reference-checks.md` | checking that references exist and say what is claimed |
| `references/scientific-files.md` | reading or writing scientific file formats |
| `references/latex-projects.md` | a workspace with ah.yaml, or starting a paper, grant or thesis in LaTeX |
| `references/latex.md` | compiling or fixing LaTeX |
| `references/remote-compute.md` | paid GPU or cloud compute (always ask first) |

Tool-name mapping and what to do when a named tool is missing are in the research mode notes and at the top of each file.
